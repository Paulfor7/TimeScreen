# TimeScreen

Windows 本地项目计时与统计软件。主页包含项目列表和当日统计两个板块，项目行内提供开始、暂停、继续、完成和提前结束操作。

## 使用

从 GitHub Releases 下载 `TimeScreen-1.0.2.exe`，双击启动便携版，无需安装开发环境。升级时先退出旧版；数据保存在原来的应用数据目录中。也可运行 `release/win-unpacked/TimeScreen.exe`，该文件必须与同目录的资源一起保留。

- 在主页或「我的项目」新建项目，设置名称、颜色、图标和描述。
- 项目编辑中的「导入 Logo」支持 PNG、JPG、WebP、ICO，最大 4 MB，保留透明背景。保存后显示在主页和项目列表；「移除 Logo」恢复默认图标。取消编辑不会修改原 Logo。
- 在主页选择正向计时或倒计时，然后点击项目行上的播放按钮。一次仅运行一个计时。
- 暂停按钮暂停或继续；勾选按钮完成并保存；方形按钮提前结束并保存已用时间。
- 开启番茄休息后，每次完成专注会进入休息；默认每 4 次安排长休息。休息结束后手动开始下一次计时。
- 「时间统计」支持日、周、月、项目用时占比、趋势与小时分布；「专注记录」可按日期、项目筛选并添加备注。
- 「专注记录 → 手动添加记录」可补录项目、开始时间、专注时长（1–1440 分钟）和备注，也支持已归档项目。保存后标注「手动添加」，按已完成记录计入统计与导出，不触发番茄休息。结束时间不能在未来，与已有记录或当前计时重叠的时段不能重复录入；跨日用时自动拆分。
- 归档项目只从进行中列表隐藏，所有用时与历史记录保留；可随时恢复项目。
- 「偏好设置」可调整时长、每日目标、提示音，上传本地背景并调整遮罩，导入或导出 JSON 备份。
- 背景遮罩支持 0–95%，数值越小图片越清晰。图片导入时校验并压缩，Logo 与背景均包含在 JSON 备份中，不依赖原图片路径。
- 统计页可以导出全部记录为 CSV。

## 统计与保存规则

统计以保存的专注时段为准，暂停和休息不计入。跨日记录按实际发生日期拆分，周从周一开始。提前结束的实际用时计入统计，次数单独显示。日均时长按所选周期中已过的自然日（含当天）计算。

正常关闭时会保存当前计时，重开后自动暂停；电脑睡眠时自动暂停。运行中每 5 秒保存一次快照，异常退出最多可能丢失最近 5 秒。应用关闭期间不继续计时。

桌面数据位于 `%APPDATA%/TimeScreen/timescreen.json`（以 Electron 的应用数据目录为准），相邻的 `.bak` 文件为上一版备份。JSON 导出不包含正在进行的计时。导入备份会替换现有数据，需要确认；建议先导出备份。数据无账号、无云同步。

## 开发

需要 Node.js 20.19+。

```powershell
npm ci
npm run dev      # 浏览器开发预览
npm start        # 构建并启动 Electron
npm test         # 时间聚合与数据校验测试
npm run build    # 构建前端
npm run dist     # 打包 Windows 便携版
```

`tests/ui.mjs` 验证浏览器交互；`tests/desktop.mjs` 验证已打包应用的本地保存与关闭恢复。浏览器测试先运行 `npx playwright install chromium`，再启动 `npm run dev`。如需使用自定义浏览器，可设置 `CHROME_PATH` 环境变量。

技术组成：Electron、Vite、原生 JavaScript、SVG 图表、Lucide 图标。应用所有页面和图标离线可用。

## 发布与隐私

当前版本：1.0.2。源码上传包不包含运行数据、JSON/CSV 备份、本地截图、缓存、依赖目录或构建产物。应用首次在新的数据目录启动时，项目和专注记录为空。

源码用于 GitHub 仓库；`TimeScreen-1.0.2.exe` 单独上传到 GitHub Releases。请勿直接上传整个本地工作目录，也不要把 `%APPDATA%/TimeScreen` 或 `.local` 中的数据附加到 Release。
