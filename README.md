# TimeScreen


Windows 本地项目与事件计时统计软件。主页包含可折叠的项目 / 事件列表和当日统计两个板块，事件行内提供开始、暂停、继续、完成和放弃本次操作。

## 使用

推荐安装版为 `release/TimeScreen-Setup-1.4.0.exe`，运行安装程序后使用桌面或开始菜单快捷方式启动，无需开发环境。便携版为 `release/TimeScreen-1.4.0.exe`；本地文件存在不代表已上传 GitHub，远程 Release 状态需另行核实。升级时先退出旧版，数据保存在原来的应用数据目录中。也可运行 `release/win-unpacked/TimeScreen.exe`，该文件必须与同目录的资源一起保留。

- 在主页或「事件与项目」新建事件，设置名称、性质、图标、描述和所属项目，事件颜色由软件自动独立分配。
- 「新建项目」建立文件夹式分组，可折叠收纳事件。在「编辑事件 → 所属项目」中，或将事件拖到项目 / 独立事件区域上，可灵活移入、移出或更换项目；在项目右侧点击 ＋ 可直接新建所属事件。事件列表行不显示归属选择框。
- 事件归属改变后，所有历史用时按当前归属汇总。解散项目会把事件移回独立事件，事件和历史记录保留。升级前的计时项作为独立事件继续使用。
- 事件编辑中的「导入 Logo」支持 PNG、JPG、WebP、ICO，最大 4 MB，保留透明背景。保存后显示在事件列表；「移除 Logo」恢复默认图标。取消编辑不会修改原 Logo。
- 在主页选择正向计时或倒计时，然后点击事件行上的播放按钮。一次仅运行一个计时。
- 暂停按钮暂停或继续；勾选按钮完成并保存；方形按钮「放弃本次」确认后丢弃当前计时，不生成记录、不计入统计、不触发休息。
- 开启番茄休息后，每次完成专注会进入休息；默认每 4 次安排长休息。休息结束后手动开始下一次计时。
- 「时间统计」支持日、周、月、用时占比、趋势与小时分布。「事件＋项目」中项目色块包围所属事件子扇区，图例以项目为表头缩进展示事件；独立事件单独占据扇区。「纯事件」逐事件显示；「纯项目」汇总项目，未归类事件仍单独显示。项目与事件使用独立且可区分的图表颜色，颜色在视图切换、移动归属和重启后保持一致。图例百分比均按总用时计算，各层不重复计时。当日统计也支持这些视图。
- 「专注记录」以大月历为主，每天显示总时长、按用时占比绘制的事件色块和主要事件提示；点击日期查看当天明细，也可多选性质、项目和事件筛选。跨日记录按实际时段拆分。日历、明细色点与统计图使用同一套颜色；导出 CSV 同时包含项目与事件名称。
- 主页与统计页使用统一图例：项目作为表头，所属事件缩进并用细竖线连接，独立事件正常排列；不显示身份小标签和分组外框。
- 每条记录右侧提供编辑和删除按钮。编辑可修改事项、开始时间、结束时间、专注时长和备注，也可选择已归档事件。保存或删除后立即更新统计，删除需要确认。仅修改事项或备注会保留原暂停时段；修改时间或时长时，专注和暂停时段按原比例调整。专注时长不能超过起止时间范围，修改后的专注时段不能与其他记录或当前计时重叠。
- 「专注记录 → 手动添加记录」可补录事件、开始时间、专注时长（1–1440 分钟）和备注，也支持已归档事件。保存后标注「手动添加」，按已完成记录计入统计与导出，不触发番茄休息。结束时间不能在未来，与已有记录或当前计时重叠的时段不能重复录入；跨日用时自动拆分。
- 归档事件只从进行中列表隐藏，所有用时、项目归属与历史记录保留；可随时恢复事件。
- 「偏好设置」可调整时长、每日目标、提示音，上传本地背景并调整遮罩，导入或导出 JSON 备份。
- 背景遮罩支持 0–95%，数值越小图片越清晰。图片导入时校验并压缩，Logo 与背景均包含在 JSON 备份中，不依赖原图片路径。
- 「偏好设置 → 空间外观」可调整面板透明度（0–100%）、字体与字号（80–130%），即时预览。透明度只作用于面板背景，不会降低文字透明度。字体使用本机已安装的字体，缺失时自动回退。项目收纳、统计视图和外观设置均保存在本机，包含在备份中。
- 毛玻璃程度可独立调为 0–40 px，0 为不模糊。字体选项还包括文字颜色与字重，并可恢复默认字体设置；恢复字体不会改变毛玻璃或透明度。文字颜色不影响图表、日历色块和记录色点的事件配色。
- 统计页可以导出全部记录为 CSV。

## 统计与保存规则

统计以保存的专注时段为准，暂停和休息不计入。跨日记录按实际发生日期拆分，周从周一开始。旧版已有记录继续保留并统计；新版放弃的计时不生成记录。日均时长按所选周期中已过的自然日（含当天）计算。

正常关闭时会保存当前计时，重开后自动暂停；电脑睡眠时自动暂停。运行中每 5 秒保存一次快照，异常退出最多可能丢失最近 5 秒。应用关闭期间不继续计时。

桌面数据位于 `%APPDATA%/TimeScreen/timescreen.json`（以 Electron 的应用数据目录为准），相邻的 `.bak` 文件为上一版备份。JSON 导出不包含正在进行的计时。导入备份会替换现有数据，需要确认；建议先导出备份。数据无账号、无云同步。

## 开发

需要 Node.js 20.19+。

```powershell
npm ci
npm run dev      # 浏览器开发预览
npm start        # 构建并启动 Electron
npm test         # 时间聚合与数据校验测试
npm run build    # 构建前端
npm run dist     # 打包 Windows 安装版与便携版
npm run dist:installer # 仅构建安装版
```

`tests/ui.mjs` 验证浏览器交互；`tests/desktop.mjs` 验证已打包应用的本地保存与关闭恢复。浏览器测试先运行 `npx playwright install chromium`，再启动 `npm run dev`。如需使用自定义浏览器，可设置 `CHROME_PATH` 环境变量。

技术组成：Electron、Vite、原生 JavaScript、SVG 图表、Lucide 图标。应用所有页面和图标离线可用。

## 发布与隐私

当前源码版本：1.4.0；推荐安装包为 `release/TimeScreen-Setup-1.4.0.exe`。源码上传包不包含运行数据、JSON/CSV 备份、本地截图、缓存、依赖目录或构建产物。应用首次在新的数据目录启动时，项目和专注记录为空。

源码与构建产物分开交付，安装包或便携版可按需单独上传 GitHub Releases，实际远程状态需核实。请勿直接上传整个本地工作目录，也不要把 `%APPDATA%/TimeScreen` 、`.local`、`reports` 中的个人数据附加到 Release。

- 专注记录标题融入日历，手动添加入口放在右侧明细列表。事件自动分配独立颜色；导入 Logo 支持框选、移动与缩放裁剪。

## 性质、统计与打卡

- 事项性质：在新建或编辑事件、项目时选择，可直接新增性质；项目指定性质后所属事件统一跟随，或选择让事件各自设置。计时、手动记录与打卡自动使用事件性质。
- 统计和日历支持多选性质、项目和事件。性质与事项条件取交集，项目包含其下所有事件，重叠选择不重复累计。未选事件表示空结果，“全部事件 / 项目”恢复全选。
- 统计页面可将当前周期（日/周/月）、图例方式、性质和事项筛选保存为默认，重新进入页面或重启后生效；初次默认只看“主要”。
- 新建打卡事件后可在主页标记今天已做，再点一次取消；日历支持补录过去日期和删除打卡。每天每事件一条，打卡按次数统计，不计入专注时长。所有计时和打卡事件自动分配独立颜色。
- 专注趋势使用保形平滑曲线，不改变采样数值。

## 1.3.2 性质文件夹

- 性质属于事件和项目，均可在编辑中修改。修改后，历史计时与打卡按事项当前性质归类，时长与原记录保留。
- 首页使用独立的“性质分类”文件夹导航，计时区不再提供性质选择。切换文件夹只浏览相应事件和项目，不修改事项归属。
- 事件移入已指定性质的项目后自动跟随，移出或解散项目时保留当时性质。
- 性质仅存于事件和项目中；计时和打卡记录只关联事件。旧版记录上的独立性质标签被移除，全部时间及日期保留。未设置性质的旧事件归入“主要”，明确设置过的事件或项目性质保留。

## 1.3.3 日历打卡修复

- 补录打卡保存成功后自动打开对应日期，并仅扩展显示新事项所需的性质和事项筛选，避免记录已保存却看不见；手动计时补录同步修正。
- 尚无打卡事项时，新建完成后继续打开打卡记录表单；表单也可直接新建更多打卡事项，并保留填写日期。
- 日历显示独立颜色圆点、事项名称和每日打卡数；同一天多项打卡保留所有颜色标记。被筛选隐藏的已有记录提供提示和显示全部入口。
- 添加、删除及主页取消打卡等待本地写入后再确认；保存失败显示错误并撤回未保存变更。
- 回归验证包括跨月日期、筛选、新建、重复打卡、归档历史、删除、取消、写入失败和重启保存。

## 1.3.4 安装版与快捷方式

- 推荐使用 `release/TimeScreen-Setup-1.4.0.exe` 安装，程序保留在固定目录，自动创建桌面和开始菜单快捷方式。安装前完全退出旧版。
- 原来的任务栏白色图标请右键取消固定；安装后通过新桌面快捷方式启动，再固定到任务栏。不要从便携版解压出来的临时目录创建快捷方式。
- 应用 EXE 已嵌入 TimeScreen 图标和版本信息；窗口、安装快捷方式使用同一 AppUserModelID。便携版窗口重新启动目标使用原始便携启动器，而非临时 EXE；保留便携 EXE 的路径才可继续使用该快捷方式。
- 原数据目录仍为 `%APPDATA%/timescreen`，升级沿用原有记录；安装程序不要求清除数据，卸载默认保留数据。
- 构建全部 Windows 版本：`npm run dist`；仅构建安装包：`npm run dist:installer`。

## 1.4.0 小浮窗

- 点击主界面右上角“小浮窗”，以置顶小窗口显示当前事件、项目、本次计时、今日事项及项目用时；与主界面共用同一条计时，不重复创建记录。
- 支持拖动顶部、切换置顶、暂停/继续、完成保存、倒计时与番茄休息，以及恢复主窗口。关闭程序后记住浮窗模式、置顶状态和位置；显示器变更时将位置调整回可见区域。
- 浮窗图片按钮可导入独立背景，右侧 × 移除；偏好设置的“浮窗背景”支持上传和背景遮罩调节，不改变主界面背景。
- 计时和打卡仍保存在 `timescreen.json`，仅浮窗位置等窗口状态保存在同目录的 `window-state.json`；重新打开时未完成计时仍按原规则暂停恢复。
